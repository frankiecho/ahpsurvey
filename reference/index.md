# Package index

## All functions

- [`ahp()`](https://frankiecho.github.io/ahpsurvey/reference/ahp.md) :
  Canned routine for AHP

- [`ahp.aggjudge()`](https://frankiecho.github.io/ahpsurvey/reference/ahp.aggjudge.md)
  : Aggregate individual judgments

- [`ahp.aggpref()`](https://frankiecho.github.io/ahpsurvey/reference/ahp.aggpref.md)
  : Aggregate priority weights

- [`ahp.cr()`](https://frankiecho.github.io/ahpsurvey/reference/ahp.cr.md)
  : Calculates the consistency ratio of each decision-maker

- [`ahp.error()`](https://frankiecho.github.io/ahpsurvey/reference/ahp.error.md)
  : Matrix of the product between the pairwise comparison value and
  pj/pi

- [`ahp.harker()`](https://frankiecho.github.io/ahpsurvey/reference/ahp.harker.md)
  : Replace inconsistent pairwise comparisons

- [`ahp.indpref()`](https://frankiecho.github.io/ahpsurvey/reference/ahp.indpref.md)
  : Computes priority weights of individual decision-makers

- [`ahp.mat()`](https://frankiecho.github.io/ahpsurvey/reference/ahp.mat.md)
  : Generate AHP pairwise matrices from survey data

- [`ahp.md()`](https://frankiecho.github.io/ahpsurvey/reference/ahp.md.md)
  : Replace inconsistent pairwise comparisons with the maximum deviation
  method

- [`ahp.missing()`](https://frankiecho.github.io/ahpsurvey/reference/ahp.missing.md)
  : Impute missing observations using the maximum deviation method.

- [`ahp.pwerror()`](https://frankiecho.github.io/ahpsurvey/reference/ahp.pwerror.md)
  : Finds the pairwise comparisons with the maximum amount of
  inconsistency

- [`ahp.ri()`](https://frankiecho.github.io/ahpsurvey/reference/ahp.ri.md)
  : Generate random indices

- [`ahpsurvey`](https://frankiecho.github.io/ahpsurvey/reference/ahpsurvey.md)
  :

  `ahpsurvey`: Analytic Hierarchy Process for Survey Data

- [`city1`](https://frankiecho.github.io/ahpsurvey/reference/city1.md) :
  Dataframe of one decision-maker based on Saaty (2004)

- [`city200`](https://frankiecho.github.io/ahpsurvey/reference/city200.md)
  : A dataframe of 200 simulated decision-makers based on Saaty (2004)
